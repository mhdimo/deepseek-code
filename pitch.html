Why terminal-native

Where you already work,
minus the busywork

DeepSeek Code is built for the same muscle memory as git, vim, and tmux — and engineered around three ideas.

⚡

Speed

A native C++ agent engine (ai-sdk-cpp) drives the agentic loop — streaming, memory, compaction, retries — so the TS layer only paints pixels.

  • 80ms batched streaming flushes, flicker-free Ink rendering
  • Startup in milliseconds — no Electron, no server
  • Zero-config launch from any directory
🛡️

Control

Every write, edit, and command runs through a permission pipeline with diff previews, rule-based allow/deny/ask, and read-only plan mode.

  • Shift+Tab permission modes: default → accept edits → plan → bypass
  • PreToolUse / PostToolUse shell hooks
  • Root/sudo bypass gate — refuses unsafe runs
🧩

Extensibility

MCP servers, SKILL.md skills, lifecycle hooks, plugins, custom agents and commands — the agent grows with your workflow.

  • MCP tool sets over stdio and HTTP
  • Project, user, and bundled skills with precedence
  • Plugin marketplace browsing built in

Safety & permissions

An agent you can trust
with your keyboard

DeepSeek Code never touches your files or shell without asking — unless you say otherwise. The permission engine is checked before every tool call:

  • Rule engine first — allow/deny/ask rules win before any prompt is shown
  • Diff previews on every Write/Edit, with Tab to attach feedback
  • Plan mode hard-denies write/execute tools
  • Hooks gate execution — PreToolUse can block with a reason
  • Root guard — refuses --dangerously-skip-permissions as root outside a sandbox
  • Abort-safe — every tool races against the abort signal
~/.deepseek-code/settings.jsonpermissions
// Tool(spec:pattern) rule language
{
  "permissions": {
    "allow": [
      "Bash(npm test:*)",
      "Read(src/**)",
      "Edit(src/**)",
      "WebFetch(*)"
    ],
    "deny": [
      "Bash(git push:*)",
      "Bash(rm -rf *)"
    ],
    "ask": [
      "Write(*)"
    ]
  }
}

Extensibility

Not a walled garden

Five extension points, each with first-class support.

🔌

MCP servers

Declare mcpServers in config (stdio or HTTP), toggle them at runtime with /mcp enable|disable, and the native engine mounts them as tool sets. Active servers show in the status bar.

📚

Skills

Drop a SKILL.md in .claude/skills/, ~/.claude/skills/, or use the bundled ones. The Skill tool's description embeds the live catalog — the model loads expertise on demand.

🪝

Lifecycle hooks

Shell hooks on PreToolUse (blocking), PostToolUse, UserPromptSubmit, Stop, and Notification — configured in settings.json.

🧩

Plugins

/plugins opens plugin management — installed plugins plus marketplace browsing, all in-app.

🤖

Custom agents & commands

Define your own agents and slash commands with their own system prompts — same pipeline as the built-ins.

🎨

Themes & output styles

Claude-Code-style design system with auto/dark/light/daltonized/ansi themes and configurable output styles.

Workflow & sessions

Built for real work, not demos

💾

Sessions that persist

Every session is saved to ~/.deepseek-code/sessions. Resume any time with --resume <hash>.

⏪

/rewind with file snapshots

Truncate history to any message — and restore the actual file contents from per-message snapshots.

🔎

/search your transcript

Full-transcript search with regex support. /export to markdown or JSON.

📥

Queued prompts

Type while the agent works — prompts queue up and drain automatically. Ctrl+Q to cancel the queue.

🔄

Background tasks

Long-running commands via run_in_background, tailed with TaskOutput, killed with process-group semantics.

🤖

Headless CI mode

--print "fix the tests" --output-format json --max-turns 20 — the same agent, scriptable. JSON envelope for automation.

📈

Cost & usage tracking

Live token counts, per-session cost estimates, usage heatmaps and streaks (/cost, /usage, /stats).

💊

Recovery built in

413 prompt-too-long → /compact advice. 429 overload → one-shot retry on a fallback model. Never a dead spiral.

📄

Project context auto-load

CLAUDE.md, DEEP.md, AGENTS.md — plus git branch — are injected into the system prompt automatically.

🔔

Desktop notifications

Optional notifications when the agent finishes — and preventSleep during long runs.

Get started

Up and running in 60 seconds

One dependency (Bun), one API key, zero ceremony. Clone, install, and start pairing.

  1. 1 Install Bun — curl -fsSL https://bun.sh/install | bash
  2. 2 git clone this repo & bun install
  3. 3 Set your DEEPSEEK_API_KEY (or run /setup)
  4. 4 Run bun run dev and start typing
➜ export DEEPSEEK_API_KEY="sk-..."
➜ bun run dev

# headless for CI / scripts
➜ bun dist/index.js --print "fix the tests" \
      --output-format json --max-turns 20

# reasoning effort
➜ bun dist/index.js --effort max

# resume yesterday's session
➜ deepseek-code --resume a1b2c3d4
